# CLI Music Player

## Requirements

- macOS
- Node.js
- MP3 files

## Run the player

1. Open Terminal.
2. Go to the project folder:

   ```sh
   cd /Users/kushagargargsmacbook/Appdevelective/Lecture-17-aug/cli-music-player
   ```

3. Start the player:

   ```sh
   node cli_player.js
   ```

4. When asked for the music folder, enter the complete path to the folder. For the songs included with this project, enter:

   ```text
   /Users/kushagargargsmacbook/Appdevelective/Lecture-17-aug/cli-music-player/songs
   ```

   For a different folder, replace this with that folder's full path from the root of your computer. You can also type `c` to use the current folder.

5. Enter the number of the song that you want to play.
6. Type `Yes` to confirm.

The selected song will start playing.

## Stop the player

Close the Terminal window or press `Control+C`.
